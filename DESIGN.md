# TaskFlow — UI/UX Design Guide

## Философия дизайна

TaskFlow должен быть **похож на Jira по функционалу, но проще и приятнее визуально**.

- **Меньше шума.** Убираем лишние границы, тени и разделители. Контент важнее декора.
- **Предсказуемость.** Привычные паттерны: sidebar слева, топбар сверху, карточки задач как в Kanban.
- **Быстрая навигация.** Всё важное — в 1-2 клика.
- **Российский/SaaS-интерфейс.** Чистый, нейтральный, профессиональный.

```
├──────────┬──────────────────────────────────────────────────┤
│          │                                                  │
```

### Sidebar

- Тёмная левая панель (slate-900)
- Вверху логотип TaskFlow
- Ниже навигация по разделам:
  - Дашборд
  - Проекты
  - Wiki
- Внизу — профиль пользователя и кнопка выхода
- Активный пункт подсвечивается primary-цветом

### TopBar

- Белая панель с нижней границей
- Слева: заголовок страницы + название workspace
- Справа: глобальный поиск, кнопки действий, колокольчик уведомлений

```
│ ┌─────────┐ │ │ ┌─────────┐ │ │ ┌─────────┐ │ │ ┌─────────┐ │
│ │ Task    │ │ │ │ Task    │ │ │ │ Task    │ │ │ │ Task    │ │
│ │ TF-12   │ │ │ │ TF-15   │ │ │ │ TF-18   │ │ │ │ TF-9    │ │
│ │ 👤      │ │ │ │ 👤      │ │ │ │ 👤      │ │ │ │ 👤      │ │
│ └─────────┘ │ │ └─────────┘ │ │ └─────────┘ │ │ └─────────┘ │
│ ┌─────────┐ │ │             │ │ │ ┌─────────┐ │ │ ┌─────────┘ │

│ └─────────┘ │ │             │ │ │ └─────────┘ │ │ │           │
└─────────────┘ └─────────────┘ └─────────────┘ └─────────────┘
```

### Правила отображения

- Колонки фиксированной ширины (320px)
- Горизонтальный скролл при большом количестве колонок
- Заголовок колонки: название + счётчик задач
- Фон колонки: `#f1f5f9`
- Внутренний отступ: 12px
- Gap между карточками: 12px

### Карточка задачи

```
┌─────────────────────────┐
│ [Task]    [Major]       │  ← тип и приоритет
│                         │
│ Добавить фильтр по      │  ← заголовок
│ дате создания           │
│                         │
│ TF-42          [А]   3SP│  ← ключ, аватар, story points
└─────────────────────────┘
```

#### Элементы карточки

- Верхняя строка: Badge типа (слева) + Badge приоритета (справа)
- Заголовок: 14px, font-weight 500, максимум 2 строки
- Нижняя строка:
  - Ключ задачи моноширинным шрифтом
  - Аватар assignee (или `?` если не назначен)
  - Story points (если указаны)

#### Состояния

- Default: белый фон, граница slate-200
- Hover: тень, граница primary-300, курсор pointer
- Drag: повышенная тень, слегка повёрнута

## Страница задачи

### Модальное окно (MVP)

В MVP используем модалку вместо отдельной страницы:

```
┌─────────────────────────────────────────┐
│  TF-42: Добавить фильтр по дате    [×]  │
├─────────────────────────────────────────┤
│                                         │
│  Тип: Task              Приоритет: Major│
│  Статус: In Progress                    │
│                                         │
│  Описание:                              │
│  [Markdown-контент]                     │
│                                         │
│  ── Комментарии ──                      │
│  [Аватар] Текст комментария             │
│                                         │
└─────────────────────────────────────────┘
```

### Поля задачи

- Ключ + название в заголовке
- Блок мета-информации: тип, приоритет, статус, assignee, reporter
- Описание с Markdown
- Вкладки/секции: Комментарии, Time logs, Связанные задачи

## Компоненты интерфейса

### Кнопки

- **Primary:** indigo-600 фон, белый текст, скругление 8px
- **Secondary:** белый фон, slate-700 текст, граница slate-300
- **Ghost:** прозрачный фон, hover slate-100
- **Danger:** red-600 фон

### Inputs

- Граница slate-300, скругление 8px
- Focus: кольцо primary-500
- Label над полем

### Модалки

- Центрированы
- Белый фон, скругление 12px
- Тень xl
- Шапка с заголовком и крестиком
- Футер с кнопками действий

### Badges

- Маленькие pill-элементы
- Цвет зависит от статуса/приоритета/типа
- Используется полупрозрачный фон (color + 20% opacity)

### Аватары

- Круглые, 24–32px
- Если нет фото — инициалы пользователя на цветном фоне

- Глобальный поиск в топбаре
- Cmd/Ctrl + K для быстрого вызова
- Результаты группируются по типам: Задачи, Wiki, Файлы
- Иконка типа слева от результата

## Адаптивность

MVP ориентирован на десктоп. Мобильная версия — Nice to Have.

### Десктоп (основной)

- Sidebar всегда виден
- Доска с горизонтальным скроллом

### Планшет

- Sidebar можно свернуть
- Двухколоночные сетки → одноколоночные

### Мобильный (будущее)

- Sidebar в нижний таббар или гамбургер-меню
- Доска в виде списка

## Принципы взаимодействия

1. **Мгновенная обратная связь.** Кнопки имеют hover/focus состояния. Формы валидируются до отправки.
2. **Подтверждение опасных действий.** Удаление задачи/проекта требует подтверждения.
3. **Контекстное меню.** Правая кнопка мыши на задаче → редактировать, удалить, назначить.
4. **Drag & Drop.** Перемещение задач между колонками.
5. **Упоминания.** `@user`, `#task`, `[[page]]` подсвечиваются и кликабельны.
